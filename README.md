# Tirthraj's Projects for Networking

A responsive static networking portfolio designed for GitHub Pages.

## Publish with GitHub Pages

1. Sign in to GitHub and create a public repository named `tirthraj-networking-projects`.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will display the published site URL in the Pages settings.

## Customize

- Add project cards inside the `#projects` section in `index.html`.
- Replace or expand the About text after verifying public profile details.
- Add an email or phone number only if you intentionally want it publicly visible.
